# Team Fortress 3

## Building the Project in Unity

To build and run the game on your local machine, follow the steps below:

### Prerequisites
* **Unity Engine:** Version 6000.3.10f1.
* **Git:** To clone the project repository.

### Build Instructions
1. **Clone the Repository:**
   Open your terminal or command prompt and run:
   `git clone https://github.com/your-username/TeamFortress3.git`
2. **Open the Project:** Launch **Unity Hub**, click on **Add project from disk** (or **Open**), and navigate to the cloned `TeamFortress3` directory.
3. **Open Build Settings:** Once the project has finished importing and compiling its initial assets, go to the top menu bar and select `File > Build Settings`.
4. **Configure Scenes:** In the Build Settings window, ensure all required scenes are checked in the "Scenes in Build" list.
5. **Select Target Platform:** Choose your desired platform (PC, Mac, or Linux Standalone).
6. **Build and Run:** Click the **Build** button, select an empty destination folder on your computer, and wait for Unity to compile the executable. Once finished, launch the generated application file to start the game.

## Multiplayer Guide

Steam is required to play.

### Creating a Lobby
If you want to host a game:
1. Boot up the game and navigate to the **Main Menu**.
2. Select the **Create Lobby** option.
3. You will be placed into a new lobby as the host. 
4. Look for the Lobby Code displayed on your screen. You can share this unique code with other players so they can connect directly to your session.

### Joining a Lobby
If you are looking to join an existing game, you have two options from the Main Menu:

* **Option 1: Server Browser**
  1. Select the **Browse** option.
  2. A list of all currently active and public lobbies will appear.
  3. Scroll through the list, find a lobby with open slots that you wish to join, and click on it.

* **Option 2: Direct Lobby Code**
  1. Select the **Join** option.
  2. A prompt will appear asking for a code. Type in the specific Lobby Code provided to you by the creator of the lobby.
  3. Confirm your entry to instantly connect to their specific session.

### Starting the Match
Once you are inside a lobby alongside the other players, the game does not start automatically:
1. Every player in the lobby must click the **Ready** button located on their screen.
2. The match will only start if all players are ready. Once the final player clicks "Ready", the game will start.
